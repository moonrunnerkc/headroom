## Observations (no sensing)

- Startup to first window: 292–302 ms (built app, dev Electron binary).
- Total working set of all app processes: 481 MB at start, 579 MB after 600 layout and workspace switches plus typing. The renderer JS heap after forced GC stayed between 6 and 10.3 MB across the run, so the growth is outside application JS (Chromium process memory); it was not investigated further.
- Real local AI: 1.3 s (`qwen3:0.6b`), 4.8 s (`gemma4:e4b-it-q8_0`, includes model load on first call), 6.4 s (`qwen3.6:35b-a3b`). All outputs passed structural validation. The `qwen3:0.6b` answer in `live-ai-qwen3-0.6b.log` contains a factual error (it says `private` lets shared caches keep responses), which is why the UI says structural checks do not establish accuracy.
